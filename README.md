# StayScout

Where to open a stay, what to charge, what to offer, and what to fix, from live booking-site data.

**Status:** marketing website + app preview (no sample data). Backend (Netlify Database, Identity, Functions, live data via Apify/SerpApi, AI via Bifrost) is next.

## Files
- `index.html`: the website and app preview (single file)
- `netlify.toml`: Netlify publish settings and security headers
- `robots.txt`: blocks AI crawlers

## Deploy
Connect this repository to a Netlify site. No build step is needed.
